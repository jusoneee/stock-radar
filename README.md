# Stock Radar · A股行情与新闻事件雷达

> A股行情与新闻事件驱动的选股分析工具（产品框架版）。
> 当前版本已接入**真实公开接口**：东方财富全市场列表、东方财富/腾讯证券日 K 与快照、新浪财经滚动资讯；模拟适配器保留为离线兜底（`meta.simulated = true`）。分析标的由用户可维护的**自选池**决定（最多 50 只，本地持久化）。

Stock Radar 把两件通常割裂的事情放在同一个决策流程里：

1. **行情趋势**：通过多源行情计算均线结构、量能、区间位置，判断个股处于强势上行 / 温和上行 / 震荡 / 回调 / 下行；
2. **新闻事件**：对新闻事实做事件抽取、情绪标注与个股映射，判断事件处于 **发酵 → 确认 → 衰退** 的哪个阶段，并给出买卖时机参考。

两者的结果会融合成一个可解释的评分与候选清单，页面上的每一个结论都能下钻查看计算依据。

## 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 本地开发：http://localhost:5173
npm run build    # 类型检查 + 生产构建（产物在 dist/）
npm run preview  # 预览构建产物
```

环境要求：Node.js ≥ 18（开发环境实测 Node 26 / npm 11）。

当前构建状态：`npm run build` 通过（`vue-tsc --noEmit` 无类型错误，Vite 构建成功）。

真实取数实测量（2026-11-05）：

- 全市场列表：56 页、**5563 只**（沪/深 A 股），并发 3 + 150ms 间隔，实测分页耗时约 **4.2s**（单页 266ms、7.8KB），CORS `*` 可直连；
- 分析链路：10 只标的全部返回、30 条资讯，三个渠道合计 3/3 成功，总耗时约 0.7～1.2s（含日 K 逐股请求）。

## 四个可用页面

| 路由 | 页面 | 内容 |
| --- | --- | --- |
| `/` | 仪表盘 | 产品说明、分析流水线、当前渠道/自选池配置、数据新鲜度、合规声明 |
| `/watchlist` | 自选池 | 全市场搜索新增、单个删除、清空、恢复默认；交易状态与缓存新鲜度 |
| `/channels` | 数据源配置 | 行情源/新闻源开关、权重滑杆、密钥输入、请求策略，配置本地持久化 |
| `/analysis` | 分析结果 | 市场概览、渠道运行状态、候选推荐表、个股详情（指标/评分构成/风险）、新闻事件时间线 |

路由采用 hash 模式（`#/analysis`），可直接用任意静态服务器托管 `dist/`。

## 真实数据源（2026-11-05 实测）

| 渠道 | 接口 | 用途 | CORS | 限频建议 |
| --- | --- | --- | --- | --- |
| `eastmoney-universe` 东方财富 | `push2.eastmoney.com/api/qt/clist/get`（`fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23`，每页 100 条） | 全市场 A 股列表（代码/名称/最新价/涨跌幅/时间戳） | `Access-Control-Allow-Origin: *`，可直连 | 并发 ≤3，请求间隔 ≥150ms，同一交易日只抓一次 |
| `eastmoney-quote` 东方财富 | `push2.eastmoney.com/api/qt/ulist.np/get`（批量快照）+ `push2his.eastmoney.com/api/qt/stock/kline/get`（前复权日 K，120 根） | 主行情源 | 回显 Origin，可直连 | 并发 ≤3，请求间隔 ≥120ms |
| `tencent-quote` 腾讯证券 | `web.ifzq.gtimg.cn/appstock/app/fqkline/get`（日 K）+ `qt.gtimg.cn/q=`（快照，GBK） | 第二行情源，收盘价交叉校验 | `Access-Control-Allow-Origin: *` | 并发 ≤3，请求间隔 ≥120ms |
| `sina-news` 新浪财经 | `feed.mix.sina.com.cn/api/roll/get`（滚动资讯 30 条） | 新闻事件流水线输入 | **无 CORS 头**，开发环境走 `/api/sina` 代理 | ≤1 请求/秒 |

> 东方财富搜索建议接口 `searchapi.eastmoney.com/api/suggest/get` 实测返回 200 且结构可用（含 `PinYin`），但**不带 CORS 头**，因此本项目不做远程联想搜索，改为全市场列表落地到 localStorage 后本地模糊匹配（代码/名称）。

### 全市场列表与本地缓存

- **分页**：接口单页上限 100 条（传 `pz=2000` 仍只返回 100），全市场 5563 条需 56 页；适配器合并首页与其余分页，按 6 位代码去重并按代码排序。
- **风控**：分页请求并发上限 3，每请求前置 150ms 间隔；任何一页失败即整体报错并提示失败页号，不返回残缺列表。
- **缓存**：`localStorage` 键 `stock-radar:universe:v1`，带 `expiresAt`（下一个交易日 09:30）；过期后进入「自选池」页会重新抓取，过期数据仍可查看但明确标注「缓存已过期」。
- **失败可见**：列表加载失败时页面展示错误与「重试」，搜索框禁用；**不会**退回模拟列表。

### 交易日历与数据新鲜度

- 本地规则（`src/lib/trading-calendar.ts`）：周一至周五 + 2025/2026 节假日表，按 `Asia/Shanghai` 计算；输出「最近交易日」「盘中 / 午间休市 / 盘前 / 已收盘 / 休市」。
- 用于：全市场缓存 TTL、自选池页与仪表盘的状态标签、分析页「日 K 截至」与「全市场列表更新时间」提示。
- 节假日表需每年 12 月按交易所公告更新；接口 `f124` 时间戳会与本地状态并列展示，便于发现数据延迟。

### 自选池

- 位置：`/watchlist`；`localStorage` 键 `stock-radar:watchlist:v1`。
- 能力：代码/名称模糊搜索新增、单个删除、清空、恢复默认（10 只）、上限 **50 只**；空池时分析页给出明确空状态，引擎也会拒绝运行。
- 首次升级会从旧版渠道配置中的 `symbols` 迁移一次；写入失败（配额）不影响本次会话使用。

- 请求超时、重试次数、响应缓存 TTL 均可在「数据源配置」页调整（默认 8s / 1 次 / 30s）。
- 单只股票取数失败只影响该股，不会中断整轮分析；全部行情渠道失败时页面显示明确错误，不会静默使用模拟数据。
- 模拟渠道（新浪行情、Tushare、AKShare、财联社、新闻聚合）保留为离线兜底，卡片上标注「模拟数据」。

## 核心机制

**多源合并**：同类型渠道权重归一化后求和为 1；权重最高的渠道作为主行情序列，其余渠道提供收盘价交叉校验，偏差超过 0.5% 会在风险提示中告警。单个渠道失败不会中断分析，运行状态会显示在「渠道运行状态」中。

**趋势状态机**（优先级从高到低）：

```
强势上行：收盘 > MA5 > MA10 > MA20 且 5 日涨幅 > 4% 且量比 ≥ 0.9
温和上行：MA5 > MA20 且收盘 > MA10 且 5 日涨幅 > 1%
弱势下行：收盘 < MA5 且 MA5 < MA20 且 5 日跌幅 > 1.5%
高位回调：MA5 < MA10 且收盘 < MA5 但仍在 MA20 附近且区间位置 > 25%
区间震荡：以上均不满足
```

**事件生命周期**：先看文本线索（公告/官宣/签约 → 确认；传闻/据悉/拟 → 发酵；不及预期/澄清/取消 → 衰退），再看发布时间（8 小时内无落地信息视为发酵，72 小时后视为衰退）。

**评分权重**：趋势结构 40% + 动量强度 15% + 量能配合 15% + 区间位置 15% + 事件驱动 15%。事件分以 50 为中性基准，按「情绪 × 阶段 × 置信度」加/减分。

## 合规声明

- 本工具仅做**信息聚合与分析逻辑展示**，行情与资讯来自第三方公开接口，评分与「操作参考」均为规则化分析结论，**不构成投资建议**，也不构成任何证券买卖的要约或承诺。
- 一切投资决策及其后果由使用者自行承担；使用者应结合监管披露信息、自身风险承受能力独立判断。
- 所用接口均为公开、未签署商业授权协议的非官方接口，**字段与可用性不受服务方承诺**；商用或对外提供服务前，必须自行取得数据授权，并遵守《证券法》《网络安全法》及交易所信息披露相关规定。
- 真实数据接入需自行配置密钥（当前三个真实源均无需密钥）：**仓库中不得提交任何真实 API Key**；页面输入的密钥仅保存在浏览器内存中，不写入 localStorage，不进入构建产物。生产环境建议由后端代理持有密钥并统一限流。
- 如用于对外提供服务，还需评估是否涉及证券投资咨询业务资质要求。

## 当前限制

- 行情为**日线级别**：日 K 取 120 根（前复权），盘中数据以最近交易日收盘 + 实时快照为准，不做分钟级回测。
- 全市场列表覆盖沪深 A 股（不含北交所），北交所标的因行情适配器仅支持 `sh`/`sz` 前缀而排除。
- 新浪资讯无 CORS 头：开发环境依赖 Vite 代理 `/api/sina`，纯静态部署需自行加一层反向代理，否则新闻渠道会显示失败（行情与自选池不受影响）。
- 公开接口无官方 SLA，存在限流与字段变动风险；已内置超时、重试、响应缓存与批量并发限制，但仍建议控制刷新频率。
- 交易日历为本地规则 + 静态节假日表，法定调休临时通知不会自动同步；请以交易所公告为准。
- 新闻去重基于标题归一化字符串，事件抽取为关键词规则，未接入 NER / LLM；个股映射依赖显式代码与公司名匹配，泛行业新闻通常不会命中股票池。
- 行情接口返回的「最新价」为最近成交价，非复权价格，与日 K 前复权序列存在口径差异，评分以序列指标为主。
