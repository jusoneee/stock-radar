# Stock Radar · A股行情与新闻事件雷达

> A股行情与新闻事件驱动的选股分析工具（可本地运行的功能版）。
> 当前版本已接入**真实公开接口**：东方财富全市场列表（含北交所）、东方财富/腾讯/新浪日 K 与快照、新浪财经滚动资讯、东方财富 F10 公司资料；Tushare / AKShare / 财联社 / LLM 保留配置位并显式标注未启用（不伪造数据）。模拟适配器保留为离线兜底（`meta.simulated = true`）。分析标的由用户可维护的**自选池**决定（最多 50 只，本地持久化）。
>
> 2026-11 新增：**自定义数据源**（保存前强制测试连接、字段映射、代理白名单）、**个股详情页**、**2~6 只多股对比**、**统计趋势预测**（线性回归 + EMA/动量 + 波动率区间，附 walk-forward 误差与免责声明）、**收藏与多选预览**、**公司资料 + 个股舆情**、手机/平板/桌面三档响应式与 PWA manifest。

Stock Radar 把两件通常割裂的事情放在同一个决策流程里：

1. **行情趋势**：通过多源行情计算均线结构、量能、区间位置，判断个股处于强势上行 / 温和上行 / 震荡 / 回调 / 下行；
2. **新闻事件**：对新闻事实做事件抽取、情绪标注与个股映射，判断事件处于 **发酵 → 确认 → 衰退** 的哪个阶段，并给出买卖时机参考。

两者的结果会融合成一个可解释的评分与候选清单，页面上的每一个结论都能下钻查看计算依据。

## 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 本地开发：http://localhost:5173
npm run build    # 类型检查 + 生产构建（产物在 dist/）
npm run preview  # 预览构建产物
npm test         # vitest 单元测试（43 条）
npm run proxy    # 可选：零依赖生产代理 + 托管 dist/（默认 8787）
```

环境要求：Node.js ≥ 18（开发环境实测 Node 26 / npm 11）。

当前构建状态：`npm run build` 通过（`vue-tsc --noEmit` 无类型错误，Vite 构建成功）。

真实取数实测量（2026-11-05）：

- 全市场列表：约 60 页、**约 5927 只**（沪深 5563 + 北交所 364），并发 3 + 150ms 间隔，实测分页耗时约 4～5s，CORS `*` 可直连；
- 分析链路：10 只标的全部返回、30 条资讯，三个渠道合计 3/3 成功，总耗时约 0.7～1.2s（含日 K 逐股请求）；
- 新浪日 K / GBK 快照、北交所 `bj920992` 均实测 HTTP 200（无 CORS，需 Vite 代理或同域反向代理）。

### 全市场列表与本地缓存

- **分页**：接口单页上限 100 条（传 `pz=2000` 仍只返回 100），全市场约 5927 条（沪深 5563 + 北交所 364）需约 60 页；适配器合并首页与其余分页，按 6 位代码去重并按代码排序。
- **行业与状态**：`f100` 作为行业字段；`f2` 为 `-` 判停牌，名称 `/^\*?ST/` 判 ST，页面与风险提示同步展示。
- **风控**：分页请求并发上限 3，每请求前置 150ms 间隔；任何一页失败即整体报错并提示失败页号，不返回残缺列表。
- **缓存**：`localStorage` 键 `stock-radar:universe:v1`，带 `expiresAt`（下一个交易日 09:30）；过期后进入「自选池」页会重新抓取，过期数据仍可查看但明确标注「缓存已过期」。
- **失败可见**：列表加载失败时页面展示错误与「重试」，搜索框禁用；**不会**退回模拟列表。

### 交易日历与数据新鲜度

- 本地规则（`src/lib/trading-calendar.ts`）：周一至周五 + 2025/2026 节假日表，按 `Asia/Shanghai` 计算；输出「最近交易日」「盘中 / 午间休市 / 盘前 / 已收盘 / 休市」。
- 用于：全市场缓存 TTL、自选池页与仪表盘的状态标签、分析页「日 K 截至」与「全市场列表更新时间」提示。
- 节假日表需每年 12 月按交易所公告更新；接口 `f124` 时间戳会与本地状态并列展示，便于发现数据延迟。

### 自选池

- 位置：`/watchlist`；`localStorage` 键 `stock-radar:watchlist:v1`（保存 `{ items, sortMode }`）。
- 能力：代码/名称模糊搜索新增、分组（默认「未分组」）、排序（手动顺序 / 名称 / 代码 / 添加时间）、上/下移、单个删除、清空、恢复默认（10 只）、上限 **50 只**；空池时分析页给出明确空状态，引擎也会拒绝运行。
- 首次升级会从旧版渠道配置中的 `symbols` 迁移一次；写入失败（配额）不影响本次会话使用。

### 分析、导出与快照

- 请求超时、重试次数、响应缓存 TTL 均可在「数据源配置」页调整（默认 8s / 1 次 / 30s）。
- 单只股票取数失败只影响该股，不会中断整轮分析；全部行情渠道失败时页面显示明确错误，不会静默使用模拟数据。
- 个股详情：SVG 蜡烛图（MA5/10/20 + 成交量，最近 60 根）、指标摘要、评分构成、风险提示、事件时间线。
- 结果筛选：行业、趋势、评分区间、事件阶段、新闻情绪与排序（评分 / 当日涨跌 / 量比 / 名称）；导出 CSV / JSON（带 BOM 与免责声明），单股报告可导出 Markdown。
- 快照对比：每轮分析可保存快照（最多 8 条），对比评分、趋势与事件阶段变化。
- 评分权重：`/channels` 可调五维权重（滑杆 + 归一化展示 + 恢复默认），并持久化到 localStorage。
- 模拟渠道（新闻聚合，以及未配置凭据时的 Tushare / AKShare / 财联社）只在显式离线兜底时启用；真实渠道卡片标注「真实数据」，失败时显示错误码而非伪造数据。

## 新增能力（2026-11）

### 自定义数据源

- 入口：`/channels` → 「自定义数据源」→ 展开「新增自定义源」。
- 字段：名称、类型（行情 / 资讯）、URL 模板（支持 `{symbol}` 占位）、GET/POST（POST 支持 JSON 模板）、超时（2～60s）、可选 Token、是否经本地代理、字段映射（点路径或 JSONPath 子集，如 `data.price`、`data.klines`、`items[0].title`、`list[*].close`）。
- **保存前必须测试连接**：展示 HTTP 状态、耗时、解析样本条数与示例；失败时给出可读原因（`CORS` / `TIMEOUT` / `HTTP` / `NOT_JSON` / `MISSING_FIELD` / `FORMAT` / `PROXY` / `NETWORK`）。配置一旦改动，测试结果失效，需重新测试才能保存。
- **实测样例**（2026-11-05，浏览器内直连）：东财 K 线 `https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.{symbol}&…&lmt=60`，默认字段映射（`bars → data.klines`、`name → data.name`）→ HTTP 200 / 109ms / 60 根日 K / 名称「贵州茅台」，保存后参与分析（渠道运行状态显示「东财K线自定义 6 条 · 629ms」，其余标的因 `secid` 市场前缀不适配而失败，属模板本身的限制）。
- **持久化**：配置写入 `localStorage` 键 `stock-radar:custom-sources:v1`；Token 仅存内存，刷新即清除，并明确标注风险。
- **安全边界**：勾选「经本地代理」时请求发往 `/api/custom?target=…`，服务端按 `CUSTOM_SOURCE_ALLOWLIST`（`host|pathPrefix` 列表）校验协议（仅 https）、域名与路径前缀，拒绝 URL 凭据、内网/私有地址；**不转发 Authorization / Cookie / 任意自定义 Header**，响应体超过 5MB 截断，20s 超时。已实测：白名单内 200，白名单外 / 内网 / 错误前缀均 403。

### 个股详情、公司资料与舆情

- 路由 `/stock/:symbol`：最新收盘、60/120 日区间涨跌、区间最高/最低、成交量（最近 / 5 日均 / 20 日均）、日 K 与成交量图、统计预测面板、公司资料、相关新闻舆情；支持加入自选 / 收藏 / 加入对比。
- 公司资料来源：东方财富 F10 `RPT_F10_BASIC_ORGINFO`（实测 HTTP 200、CORS `*`、约 370ms；字段含公司全称、注册资本、成立日期、注册地址、网站、主营业务、经营范围、公司简介）。新浪 corpinfo 与腾讯 `qt` 实测**无 CORS**，故未采用；北交所部分代码 / 新代码可能无 F10 数据，此时页面显示「暂无可用资料」并降级为「基础行情 + 新闻画像」，**不编造公司简介与注册资本**。
- 舆情：按个股聚合已启用的资讯源（内置新浪 + 自定义资讯），输出情绪分布、事件阶段、最近舆论摘要与新闻列表；无命中显示「暂无相关资讯」，失败源单独列出。

### 多股对比

- 路由 `/compare`，支持自选池点选或手动输入 6 位代码，2～6 只。
- 对齐口径：取所有已加载股票的共同交易日（最近 120 个）；首日收盘价归一化为 100；区间涨跌与日均量能基于同一组共同交易日；缺失日不插值，表格标注覆盖率与缺失天数；停牌、上市时间不足、数据源缺日均表现为缺失交易日，需结合公告判断。
- 方向概率来自独立预测模块（基于该股自身完整日 K），样本不足显示「样本不足」。

### 趋势预测（统计外推，附带误差与免责声明）

- 实现位置：`src/analysis/forecast.ts`（纯函数，与评分体系完全解耦）；UI 为 `src/components/ForecastPanel.vue`。
- 方法：对数价格线性回归斜率（55%）+ 5 日动量（15%）+ EMA12/26 结构差（15%）+ 20 日均值回归修正（15%）；波动率取 20/60 日混合标准差；以 80% 正态近似给出未来 5/10/20 日中枢、涨跌幅、上行概率与置信区间。
- **误差验证**：对每个周期做 walk-forward（默认 20 个滚动窗口），输出 MAE、MAPE 与方向命中率；UI 与接口同时展示。
- **样本不足拒绝输出**：可用样本 < 60 根时不给出预测，只显示原因。
- **免责声明**：面板固定展示「基于历史统计外推，不构成预测保证，不构成投资建议」。

### 收藏与多选预览

- 自选池升级为「收藏」语义：每条可星标收藏，旧数据平滑迁移（缺省视为收藏）；提供「只看收藏」筛选。
- 选中 2～6 只后可同时预览：并列迷你走势、最新价、20 日涨跌、20 日均量、5 日方向概率 + MAPE、新闻摘要；单卡失败可重试。
- 收藏状态与多选列表均本地持久化（`stock-radar:watchlist:v1` / `stock-radar:compare:v1`）。

### 多端适配与 PWA

- 断点：≤760px 导航收起为「菜单」按钮（`aria-expanded` / `aria-controls`），表格横向滚动，卡片单列；≤1024px 主要交互控件最小高度 44px；≥1280px 多列布局。
- 图表使用 `viewBox` 自适应；K 线图与折线图均提供 `role="img"` + `aria-label`，对比页额外提供文字摘要。
- `public/manifest.webmanifest` + `icon.svg`（standalone、主题色），仅离线壳与安装入口，**不做离线取数**。

## 核心机制

**多源合并**：同类型渠道权重归一化后求和为 1；权重最高的渠道作为主行情序列，其余渠道提供收盘价交叉校验，偏差超过 0.5% 会在风险提示中告警。单个渠道失败不会中断分析，运行状态会显示在「渠道运行状态」中。

**趋势状态机**（优先级从高到低）：

```
强势上行：收盘 > MA5 > MA10 > MA20 且 5 日涨幅 > 4% 且量比 ≥ 0.9
温和上行：MA5 > MA20 且收盘 > MA10 且 5 日涨幅 > 1%
弱势下行：收盘 < MA5 且 MA5 < MA20 且 5 日跌幅 > 1.5%
高位回调：MA5 < MA10 且收盘 < MA5 但仍在 MA20 附近且区间位置 > 25%
区间震荡：以上均不满足
```

**事件生命周期**：先看文本线索（公告/官宣/签约 → 确认；传闻/据悉/拟 → 发酵；不及预期/澄清/取消 → 衰退），再看发布时间（8 小时内无落地信息视为发酵，72 小时后视为衰退）。发布时间会映射到「影响交易日」（周末与 15:00 后顺延），时间线同时展示。

**新闻去重与旧闻**：标题 + 摘要在归一化后做字符 bigram Jaccard 聚类（阈值 0.6），同簇按渠道权重选主稿并叠加可信度；`age ≥ 72h` 或「衰退且 ≥ 48h」标记旧闻，事件分 ×0.35，并说明重复报道条数。

**评分权重**：趋势结构 40% + 动量强度 15% + 量能配合 15% + 区间位置 15% + 事件驱动 15%（默认值，可在 `/channels` 调整）。事件分以 50 为中性基准，按「情绪 × 阶段 × 置信度」加/减分。

## 合规声明

- 本工具仅做**信息聚合与分析逻辑展示**，行情与资讯来自第三方公开接口，评分与「操作参考」均为规则化分析结论，**不构成投资建议**，也不构成任何证券买卖的要约或承诺。
- 一切投资决策及其后果由使用者自行承担；使用者应结合监管披露信息、自身风险承受能力独立判断。
- 所用接口均为公开、未签署商业授权协议的非官方接口，**字段与可用性不受服务方承诺**；商用或对外提供服务前，必须自行取得数据授权，并遵守《证券法》《网络安全法》及交易所信息披露相关规定。
- 真实数据接入需自行配置密钥（当前东方财富、腾讯、新浪行情/资讯均无需密钥；Tushare / 财联社 / LLM 需要外部凭据）：**仓库中不得提交任何真实 API Key**；页面输入的密钥仅保存在浏览器内存中，不写入 localStorage，不进入构建产物。生产环境建议由 `server/proxy.mjs` 或自建网关持有密钥并统一限流。
- 如用于对外提供服务，还需评估是否涉及证券投资咨询业务资质要求。

## 当前限制

- 行情为**日线级别**：日 K 取 120 根（前复权），盘中数据以最近交易日收盘 + 实时快照为准，不做分钟级回测。
- 全市场列表覆盖沪深 + 北交所（约 5927 只）；北交所行情使用 `bj` 前缀，已接入东财/腾讯/新浪。
- 新浪行情/资讯无 CORS 头：开发环境依赖 Vite 代理（`/api/sina*`），纯静态部署需同域反向代理（或使用 `server/proxy.mjs`），否则相关渠道显示失败（行情主源与自选池不受影响）。
- 新浪行情为未复权口径，仅用于收盘价交叉校验（0.5% 阈值），不参与均线与评分计算。
- 公开接口无官方 SLA，存在限流与字段变动风险；已内置超时、重试、响应缓存与批量并发限制，但仍建议控制刷新频率。
- 交易日历为本地规则 + 静态节假日表，法定调休临时通知不会自动同步；请以交易所公告为准。
- 新闻去重使用字符 bigram 聚类而非向量语义模型；事件抽取为关键词规则，未接入 NER / LLM（LLM 仅提供配置位，默认关闭）；个股映射依赖显式代码与公司名匹配，泛行业新闻通常不会命中股票池。
- 行情接口返回的「最新价」为最近成交价，非复权价格，与日 K 前复权序列存在口径差异，评分以序列指标为主。
- **预测只是统计外推**：不包含基本面、政策、突发事件与市场情绪；walk-forward 的 MAE/MAPE/方向命中率仅代表历史滚动表现，不能保证未来误差范围；样本 < 60 根时拒绝输出。任何预测数字都不构成投资建议。
- **自定义源受 CORS 与代理白名单限制**：浏览器直连要求目标站点返回 CORS 头；经代理时只能在 `CUSTOM_SOURCE_ALLOWLIST` 内访问，且代理不转发任何凭据 Header，因此需要鉴权的第三方源无法经代理使用（这是有意的安全取舍）。`{symbol}` 仅支持单个占位符，像东财 `secid=1.{symbol}` 这类需要市场前缀的模板，跨市场时会失败。
- **公司资料不是全市场覆盖**：东财 F10 对部分北交所/新上市代码无数据，页面会显示「暂无可用资料」并降级；新闻舆情依赖新浪资讯的命中率，冷门个股常见「暂无相关资讯」。
