# Stock Radar · A股行情与新闻事件雷达

> A股行情与新闻事件驱动的选股分析工具（产品框架版）。
> 本项目当前只交付「**框架 + 产品文档**」，数据全部来自本地模拟适配器，尚未接入真实行情与新闻源。

Stock Radar 把两件通常割裂的事情放在同一个决策流程里：

1. **行情趋势**：通过多源行情计算均线结构、量能、区间位置，判断个股处于强势上行 / 温和上行 / 震荡 / 回调 / 下行；
2. **新闻事件**：对新闻事实做事件抽取、情绪标注与个股映射，判断事件处于 **发酵 → 确认 → 衰退** 的哪个阶段，并给出买卖时机参考。

两者的结果会融合成一个可解释的评分与候选清单，页面上的每一个结论都能下钻查看计算依据。

## 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 本地开发：http://localhost:5173
npm run build    # 类型检查 + 生产构建（产物在 dist/）
npm run preview  # 预览构建产物
```

环境要求：Node.js ≥ 18（开发环境实测 Node 26 / npm 11）。

当前构建状态：`npm run build` 通过（`vue-tsc --noEmit` 无类型错误，Vite 构建成功）。

## 三个可用页面

| 路由 | 页面 | 内容 |
| --- | --- | --- |
| `/` | 仪表盘 | 产品说明、分析流水线、当前渠道/股票池配置、合规声明 |
| `/channels` | 数据源配置 | 行情源/新闻源开关、权重滑杆、密钥输入、股票池勾选，配置本地持久化 |
| `/analysis` | 分析结果 | 市场概览、渠道运行状态、候选推荐表、个股详情（指标/评分构成/风险）、新闻事件时间线 |

路由采用 hash 模式（`#/analysis`），可直接用任意静态服务器托管 `dist/`。

```
│   ├── components/           # 通用 UI 组件（渠道卡、推荐表、时间线、迷你走势图…）
│   ├── views/                # 三个页面
│   ├── stores/               # Pinia：渠道配置（持久化）、分析运行状态
│   ├── router/               # 路由
│   ├── types/                # 全局领域模型
│   ├── lib/                  # 格式化与中文标签映射
│   └── styles/               # 主题样式
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```

分层约束：`views/components` 只消费 `stores`，`stores` 只消费 `analysis` + `adapters`，`analysis` 不感知 Vue，`adapters` 不感知分析规则。替换真实数据源时只需要改 `adapters` 层。

## 核心机制

**多源合并**：同类型渠道权重归一化后求和为 1；权重最高的渠道作为主行情序列，其余渠道提供收盘价交叉校验，偏差超过 0.5% 会在风险提示中告警。单个渠道失败不会中断分析，运行状态会显示在「渠道运行状态」中。

**趋势状态机**（优先级从高到低）：

```
强势上行：收盘 > MA5 > MA10 > MA20 且 5 日涨幅 > 4% 且量比 ≥ 0.9
温和上行：MA5 > MA20 且收盘 > MA10 且 5 日涨幅 > 1%
弱势下行：收盘 < MA5 且 MA5 < MA20 且 5 日跌幅 > 1.5%
高位回调：MA5 < MA10 且收盘 < MA5 但仍在 MA20 附近且区间位置 > 25%
区间震荡：以上均不满足
```

**事件生命周期**：先看文本线索（公告/官宣/签约 → 确认；传闻/据悉/拟 → 发酵；不及预期/澄清/取消 → 衰退），再看发布时间（8 小时内无落地信息视为发酵，72 小时后视为衰退）。

**评分权重**：趋势结构 40% + 动量强度 15% + 量能配合 15% + 区间位置 15% + 事件驱动 15%。事件分以 50 为中性基准，按「情绪 × 阶段 × 置信度」加/减分。

## 合规声明

- 本工具仅做**信息聚合与分析逻辑演示**，所有行情、新闻、评分均为本地生成的模拟数据，**不构成投资建议**，也不构成任何证券买卖的要约或承诺。
- 一切投资决策及其后果由使用者自行承担；使用者应结合监管披露信息、自身风险承受能力独立判断。
- 接入真实数据源前，必须确认该数据源的授权范围与使用条款（含商用、再分发、频率限制等），并遵守《证券法》《网络安全法》及交易所信息披露相关规定。
- 真实数据接入需自行配置密钥：**仓库中不得提交任何真实 API Key**；页面输入的密钥仅保存在浏览器内存中，不写入 localStorage，不进入构建产物。生产环境建议由后端代理持有密钥。
- 如用于对外提供服务，还需评估是否涉及证券投资咨询业务资质要求。

## 当前限制

- 全部渠道均为 mock 实现，`meta.simulated = true`，尚未请求任何外部接口。
- 股票池固定为 10 只演示标的，未接入全市场列表与交易日历。
- 新闻去重基于标题归一化字符串，尚未使用语义相似度或聚类。
- 事件抽取为关键词规则，未接入 NER / LLM；置信度仅用于排序参考。
