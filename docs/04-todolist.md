## 已知问题与待确认

| 问题 | 影响 | 计划 |
| --- | --- | --- |
| 关键词规则对否定句（如「不及预期传闻被澄清」）易误判 | 情绪标签可能偏差 | Phase 1 引入规则否定词处理 + LLM 复核（LLM 需外部凭据，当前未启用） |
| 交易日历为静态节假日表 | 临时调休/特别休市需手工更新 | 每年 12 月按交易所公告维护，后续可接入官方日历接口 |
| 东财搜索建议接口无 CORS 头 | 无法做远程联想搜索 | 已改为全市场列表本地模糊搜索（可用性与体验更好） |
| 全市场列表依赖单页 100 条上限，首次加载需约 60 页 | 冷启动约 4～5s | 已做并发 3 + 间隔限速与按交易日缓存，仅首次或过期时抓取 |
| 模拟数据使用固定种子，仅在离线兜底时启用 | 与真实行情口径不同 | 属预期行为；真实渠道默认开启 |
| 新浪行情 / 资讯接口无 CORS 头 | 纯静态部署时相关渠道失败 | 开发环境走 Vite 代理；生产可用 `server/proxy.mjs` 或自建同域反向代理 |
| 公开接口无官方 SLA（限频、字段变更） | 偶发失败或解析异常 | 已加超时/重试/缓存与失败降级，持续观察 |
| 事件阶段判定依赖发布时间 | 时钟偏差会偏移阶段 | 已用 `effectiveTradingDay` 对齐交易日；仍建议校时 |
| 新浪行情为未复权口径 | 与主源前复权序列存在差异 | 仅用于最新收盘价交叉校验（0.5% 阈值），不参与均线/评分计算 |
| Tushare / 财联社 / AKShare / LLM 未启用 | 少一条校验源、无公告级事件、无 AI 复核 | 属外部依赖：配置 Token/授权或自建 `/api/akshare` 服务后按文档接入；当前显式报错不伪造数据 |
