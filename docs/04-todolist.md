## 已知问题与待确认

| 问题 | 影响 | 计划 |
| --- | --- | --- |
| 关键词规则对否定句（如「不及预期传闻被澄清」）易误判 | 情绪标签可能偏差 | Phase 1 引入规则否定词处理 + LLM 复核 |
| 框架版股票池固定 10 只 | 无法覆盖全市场 | Phase 1 接入全市场列表 |
| 模拟数据使用固定种子，仅在离线兜底时启用 | 与真实行情口径不同 | 属预期行为；真实渠道默认开启 |
| 新浪资讯接口无 CORS 头 | 纯静态部署时该渠道失败（行情不受影响） | Phase 1 统一走后端网关代理 |
| 公开接口无官方 SLA（限频、字段变更） | 偶发失败或解析异常 | 已加超时/重试/缓存与失败降级，持续观察 |
| 事件阶段判定依赖发布时间 | 时钟偏差会偏移阶段 | Phase 1 统一服务端时间与交易日历 |
