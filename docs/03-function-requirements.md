# 功能需求说明

版本：v0.1（产品框架版）
范围：Vue3 + Vite 前端框架、适配器层、分析引擎、三个页面与配套文档。不含后端服务、账号体系、真实行情接入。

优先级定义：**P0** = 框架版必须交付；**P1** = 正式版第一阶段；**P2** = 后续迭代。

## 2. 非功能需求

### 2.1 性能

- 单次分析（10 只标的 + 3 个渠道）在本地环境下应在 3 秒内完成，其中 mock 延时占主要部分。
- 首屏构建产物：主包 gzip 后 < 200 KB；当前实测 51.6 KB。
- 分析过程不阻塞 UI 渲染，使用异步并发与加载态。

### 2.2 可维护性

- 目录分层固定为 `adapters / analysis / stores / views / components / types`。
- `analysis` 层不得引入 Vue / Pinia 依赖，便于单测与迁移到服务端。
- 新增数据源不改动分析逻辑与页面；新增分析规则不改动适配器。
- TypeScript `strict` 开启，构建包含 `vue-tsc --noEmit` 类型检查。

### 2.3 兼容性

- 支持 Chrome / Edge / Firefox 最近两个大版本；不承诺 IE。
- Node.js ≥ 18；本地实测 Node 26.11 / npm 11.20。
- 使用 `color-mix()` 等现代 CSS，老旧浏览器降级为无彩色标签，不影响信息层次。

### 2.4 安全

- 不在仓库、构建产物、localStorage 中存放任何真实密钥。
- 用户输入的密钥仅存在内存；页面明示「刷新即清除」。
- 外部链接（如渠道文档）使用普通跳转，不注入 HTML；所有新闻文本按纯文本渲染（Vue 默认转义）。
- 真实接入时应通过后端代理转发请求，避免浏览器直接持有高权限密钥。

### 2.5 可用性与可访问性

- 关键交互有明确文案与状态（启用数量、失败原因、空态引导）。
- 颜色不作为唯一信息载体：涨跌、情绪、阶段均配文字标签。
- 表单控件使用 `<label>` 关联，开关使用 `aria-pressed`。

## 3. 合规与风险声明

1. **非投资建议**：本工具仅用于信息聚合与分析逻辑演示，所有输出（含评分、买卖时机参考）均为算法演示结果，**不构成投资建议、不构成任何证券买卖的要约或承诺**。
2. **数据合规**：真实数据接入须遵守各数据提供方的服务条款与授权范围（含频率限制、缓存与再分发限制）；A 股信息使用须符合《证券法》《网络安全法》及交易所信息披露相关规定。
3. **密钥管理**：真实接入需自行申请并配置密钥；**不得将任何真实 API Key 提交至仓库**；生产环境建议由后端持有密钥并提供内部网关。
4. **资质提示**：如对外提供付费分析服务，需评估是否涉及证券投资咨询业务资质；本框架不提供该资质能力。
5. **算法局限**：关键词规则无法可靠处理反讽、否定、旧闻重发、多跳关系；置信度仅用于排序，不作为事实判断依据，重要结论须人工复核原文。
6. **数据局限**：行情与资讯来自第三方公开接口，字段与可用性不受服务方承诺；公司资料与新闻命中率存在覆盖缺口，页面在无数据时显式降级，不以虚构内容填充。
7. **责任边界**：使用者依据本工具所做的一切决策及其后果自行承担。

## 6. 自查发现与遗留问题（2026-11）

### 已修复

1. 个股详情页在 375/390px 下头部操作按钮不换行导致页面横向溢出 55～71px → 改为两列自适应换行，复测 0 溢出。
2. 分析页「渠道运行状态」曾显示自定义源 id → 优先解析自定义源名称。
3. 对比页未区分「缺失」与「完全无数据」→ 增加缺失天数、区间外无数据文案与对齐口径说明。
4. 平板（768～1024px）触控目标偏小 → 将 44px 规则扩展到 ≤1024px。

### 遗留（已知限制）

1. 自定义源 `{symbol}` 只能替换代码本身，无法自动加市场前缀；跨市场模板需要用户分别建源（如东财 `secid=1.{symbol}` 仅适用沪市）。
2. 部分北交所/新代码无东财 F10 数据，公司资料降级为行情+新闻画像。
3. 新闻舆情依赖新浪资讯命中率，冷门个股经常「暂无相关资讯」。
4. 经代理的自定义源无法携带鉴权头（安全取舍），需要鉴权的源只能浏览器直连且要求目标站点有 CORS。
