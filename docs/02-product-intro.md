# 产品介绍说明

## 1. 一句话介绍

Stock Radar 是一个「**行情趋势 + 新闻事件**」双引擎的 A 股选股分析工作台：用户自选信息渠道，系统拉取数据后判断个股趋势与事件阶段，输出可解释的候选清单与时机参考。

## 2. 产品定位

- **形态**：Web 单页应用（Vue3 + Vite），可本地运行、可静态托管。
- **版本**：当前为 **产品框架版（Framework Edition）**，以结构、流程和文档为主，数据为模拟数据。
- **边界**：分析演示工具，不做交易执行、不做收益承诺、不提供个股推荐服务。

## 3. 解决什么问题

| 痛点 | 传统做法 | Stock Radar |
| --- | --- | --- |
| 信息分散 | 行情软件 + 新闻 App + 公告网站来回切 | 一次配置渠道，统一拉取与合并 |
| 只看到涨跌，不知道原因 | 事后翻新闻，靠记忆对齐时间 | 新闻事件与个股自动映射 + 时间线对齐 |
| 不知道消息走到哪一步 | 凭感觉判断「是不是已经涨过了」 | 事件生命周期判定：发酵 / 确认 / 衰退 |
| 技术面与消息面冲突 | 主观权衡 | 加权评分模型 + 风险提示，保留冲突信号 |
| 结论不可信 | 「智能推荐」黑盒 | 每个评分可下钻到指标与事件依据 |

## 4. 功能概览

### 4.1 数据源配置

- 行情源：东方财富、新浪财经、Tushare Pro、AKShare（均为 mock 适配器，接口已就绪）。
- 新闻源：财联社电报、多源新闻聚合。
- 每个渠道可**开关**、可**设权重**（同类型归一化）、可填**密钥**（仅内存保存）。
- 配置持久化到浏览器 localStorage；股票池可勾选 10 只演示标的。

### 4.2 行情趋势分析

1. 并行拉取所有启用的行情渠道；
2. 按权重合并：最高权重渠道为主序列，其余渠道做收盘价交叉校验；
3. 计算指标：MA5/10/20/60、1 日与 5 日涨跌、量比、20 日区间位置、20 日波动率、5 日均额；
4. 趋势状态机判定：强势上行 / 温和上行 / 区间震荡 / 高位回调 / 弱势下行，并给出 0–100 的趋势分与判定理由。

### 4.3 新闻事件分析

1. 多源新闻去重（标题归一化），同题多源报道会提升置信度；
2. 事件抽取：政策监管、业绩财报、订单合同、并购重组、产品技术、产业链、风险事件、其他；
3. 情绪标签：利好 / 中性 / 利空（正负关键词加权比较）；
4. 个股映射：优先使用来源给出的股票代码，其次做名称匹配；
5. 阶段判定：发酵 → 确认 → 衰退，依据文本线索与发布时间；
6. 时机建议：按「情绪 × 阶段」矩阵输出回踩参与 / 等待确认 / 持有观察 / 减仓兑现 / 回避观望，并给观察窗口。

### 4.4 推荐与解释

- 综合评分 = 趋势结构 40% + 动量 15% + 量能 15% + 区间位置 15% + 事件驱动 15%。
- 个股详情展示：价格、指标网格、评分构成条、买卖时机参考、风险提示（量能不足、贴近上沿、波动偏高、单一数据源、已确认利空、多源价差）。
- 新闻时间线展示：事件类型、情绪、阶段、建议、置信度、观察窗口、阶段判定理由与命中关键词。

## 5. 分析流程

```
渠道配置
   │  行情源(权重)                     新闻源(权重)
   ▼                                     ▼
并行拉取 QuoteAdapter              并行拉取 NewsAdapter
   │                                     │
   ├─ 权重合并 / 多源校验               ├─ 标题去重 / 多源复核
   ▼                                     ▼
指标计算 → 趋势状态机                事件抽取 → 情绪 → 个股映射 → 阶段 → 时机
   └──────────────┬────────────────────┘
                  ▼
        加权评分 + 风险标记
                  ▼
   候选推荐列表 / 个股详情 / 事件时间线
```

## 6. 框架版 vs 正式版

| 能力 | 框架版（当前） | 正式版（规划） |
| --- | --- | --- |
| 行情数据 | 本地生成的模拟 K 线 | 真实渠道接入、复权处理、交易日历 |
| 新闻数据 | 内置 14 条模拟快讯 | 实时订阅、增量抓取、正文清洗 |
| 事件抽取 | 关键词规则 | NER + LLM 辅助抽取 + 人工抽检 |
| 事件去重 | 标题归一化 | 语义相似度聚类、旧闻识别 |
| 股票池 | 10 只固定标的 | 全市场 + 自选股 + 行业/概念 |
| 存储 | 浏览器 localStorage | 账号体系 + 服务端存储 |
| 回测 | 无 | 事件驱动策略的历史回测 |

## 7. 适用与不适用

**适用**：学习「趋势 + 事件」分析框架、做策略原型验证、团队内部演示、二次开发接自己的数据源。

**不适用**：实盘自动交易、需要权威实时行情的场景、需要个性化投顾建议的场景。
